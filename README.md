# SIAT MCP

MCP-сервер, который даёт LLM (Claude и другим MCP-клиентам) доступ к официальной статистике
Узбекистана с портала [siat.stat.uz](https://siat.stat.uz): 3261 индикатор по регионам, отраслям,
странам, продуктам и т.д. Каждое число возвращается вместе со ссылкой на источник.

Документы проекта:
- `RESEARCH.md` — разведка: как устроен сайт и его API, почему не обычный RAG, принятые решения;
- `ARCHITECTURE.md` — архитектура и план работ.

## Как это устроено

```
siat.stat.uz/api ─► siat-crawl ─► data/raw/*.json ─► siat-load ─► data/siat.db ─► MCP-сервер ─► Claude
                    (скачивание)   (сырые ответы)    (загрузка)    (SQLite+поиск)   (инструменты)
```

## Установка

Нужен [uv](https://docs.astral.sh/uv/). Все библиотеки ставятся в локальную папку `.venv` проекта, глобальный Python не затрагивается.

```bash
uv sync
```

## Данные

**Быстрый путь — готовая база.** Распакуйте `siat.db.zip` (прилагается к проекту) так, чтобы
получилось `data/siat.db`. В ней нет персональных данных. Больше ничего скачивать не нужно.

**Или собрать самому с сайта:**

```bash
uv run siat-crawl --limit 100   # пилот: 100 индикаторов (~2 мин)
uv run siat-crawl               # всё: ~9.8k запросов, ~1 час; можно прервать и запустить снова — продолжит
uv run siat-load                # собрать data/siat.db из сырых файлов (~секунды)
```

Скачиватель «вежливый»:
- держит паузу между запросами;
- на ответ `429 Too Many Requests` ждёт столько, сколько просит сервер.

Папка `data/` не попадает в git: в сырых ответах есть контакты сотрудников. В базу они не загружаются.

## Подключение к Claude Code

```bash
claude mcp add siat -- uv run --directory <путь-к-проекту> python -m siat.server
claude mcp get siat     # должно быть: ✔ Connected
```

После этого в новой сессии Claude Code доступны инструменты сервера.

| Инструмент | Что делает |
|---|---|
| `search_indicators` | найти индикатор по словам (ru / uz / uzc / en) |
| `browse_catalog` | ходить по дереву разделов |
| `get_indicator` | карточка: единицы, методика, периоды, разрез, предупреждения, ссылки |
| `get_data` | значения «элемент разреза × период» (≤500 за раз) |
| `rank_items` | рейтинг регионов/отраслей/стран; доли — если части складываются в итог |
| `compute_change` | изменение между периодами: абсолютное, %, среднегодовой темп |

Ещё у сервера есть ресурс `siat://indicator/{id}` и промпты `regional_comparison` и `trend_analysis`.

## Проверка качества (eval)

```bash
uv run python eval/search_check.py                    # находит ли поиск нужный индикатор
uv run python eval/make_questions.py --n 40 --seed 7  # вопросы → eval/questions.jsonl, эталон → data/eval/gold.jsonl
```

Затем в **новой** сессии Claude Code в папке проекта (там подключён сервер `siat`) дать задание:

> Ответь на каждый вопрос из eval/questions.jsonl, используя только инструменты MCP-сервера siat.
> Не открывай другие файлы проекта и не читай код. Каждый ответ — как для обычного человека:
> число с единицей измерения и строка source.citation. Если данных нет — так и скажи.
> Запиши результат в eval/answers.jsonl: по строке {"id": "q001", "answer": "<полный текст ответа>"}.

И сверить с эталоном:

```bash
uv run python eval/grade.py
```
